# MengDie Code 品牌资产

## 文件

- `mengdie-mark.svg`：Web、README、文档与高 DPI 界面的首选矢量标志。
- `mengdie-mark.png`：透明背景的高分辨率标志，适合不支持 SVG 的界面和后续 Web 资源处理。
- `internal/brand.Mark`：与图形标志同源的 CLI 字符版本。

## 使用规则

- 标志旁的产品名统一写作 `MengDie Code / 梦蝶 Code`。
- 图形本身不嵌入文字；Web 使用真实文本，便于本地化、无障碍访问和响应式布局。
- 主色为梦蝶玉 `#0F9F7F`；标志保持单色，便于终端、深浅背景和小尺寸适配。
- 标志四周至少保留图形宽度 `12.5%` 的安全空间，不拉伸、不旋转、不添加阴影。
- 深色和浅色背景均优先使用透明资产；若对比不足，应由界面容器提供纯色底，不直接改图形颜色。

## 来源与状态

当前几何方向由 OpenAI 内置图像生成工具辅助探索，再按最小折点、单色和 16px 可识别约束重绘为 SVG；透明 PNG 使用同一组折线坐标生成。终端不强行模拟矢量轮廓，而使用跨字体稳定的 ASCII 符号 `<>|<>` 表达“代码双翼 + 插入光标”。资产随本仓库按 Apache-2.0 分发。

正式注册商标、应用商店或大规模宣传前，仍应完成近似商标检索和人工视觉规范复核。
